# AI Image Detector – UI/UX Design

## Project Overview

This repository contains the UI/UX design for the **AI Image Detector** web application, created using Figma.

The application is designed to help users identify whether an uploaded image is AI-generated or captured from the real world. It provides a simple and intuitive interface where users can upload images, view the detection process, and receive classification results.

The design focuses on creating a modern, minimal, and user-friendly experience while maintaining a consistent visual identity.

## Figma Design

**Figma Prototype:** [AI Image Detector – Webpage](https://www.figma.com/design/tNIuGyPoQyQSbT2YSJ3M4f/webpage?node-id=0-1&t=gQTnh19yDD7IpkK1-1)

## Design Overview

The UI/UX design consists of two main pages:

### 1. Home Page

The Home page serves as the main interface for image detection.

**Key Components:**
- **Navigation Bar:** Provides navigation between the Home and About It pages.
- **Hero Section:** Introduces the AI Image Detector and explains its purpose.
- **Image Upload Area:** Allows users to upload an image for analysis.
- **Detection Process:** Provides visual feedback while the uploaded image is being processed.
- **Classification Results:** Displays the prediction after image analysis.

**Classification States:**
- **AI Generated:** Indicates that the uploaded image is classified as AI-generated.
- **REAL:** Indicates that the uploaded image is classified as a real-world image.

### 2. About It Page

The About It page provides information about the technology and methodology behind the AI Image Detector.

**Key Components:**
- **Introduction – Behind the Detector:** Explains the purpose of the application and its role in identifying AI-generated images.
- **What Does It Do?:** Describes how the model analyzes uploaded images to estimate their authenticity.
- **How Does It Work?:** Presents the detection process through three steps:
  1. **Upload:** Users submit an image in a supported format.
  2. **Analyze:** The detector processes the image using its underlying detection model.
  3. **Get Results:** The model provides a classification indicating whether the image is AI-generated or real.
- **Important Disclaimer:** Reminds users that predictions are estimates rather than guarantees of image authenticity.

## Visual Design and Styling

The design uses a consistent visual identity throughout both pages.

| Design Element | Description |
|---|---|
| Theme | Dark interface |
| Primary Colors | Black, dark grey, and yellow/gold |
| Typography | Modern and bold typography |
| Background | Dark geometric and textured patterns |
| Layout | Minimal, centered, and structured |
| Navigation | Simple Home and About It navigation |

The dark theme creates a modern appearance, while the yellow/gold accents highlight important elements and maintain visual consistency.

## User Flow

The main image detection workflow follows these steps:

1. **Access the Home Page:** Users open the AI Image Detector web application.
2. **Upload an Image:** Users select or drag and drop an image into the upload area.
3. **Image Analysis:** The uploaded image is processed by the underlying detection model.
4. **View Classification:** Users receive a result indicating whether the image is classified as AI-generated or real.
5. **Learn More:** Users can visit the About It page to understand the detection methodology.

## Design Objectives

The UI/UX design aims to achieve the following objectives:

- **Simplicity:** Provide an intuitive interface that requires minimal effort to use.
- **Clarity:** Present classification results in a clear and understandable manner.
- **Consistency:** Maintain consistent colors, typography, navigation, and layouts.
- **Accessibility:** Make the detection process understandable to users with different technical backgrounds.
- **Transparency:** Explain the underlying detection approach and communicate the limitations of model predictions.

## Disclaimer

The AI Image Detector provides predictions based on its underlying machine learning model. Classification results are estimates and should not be treated as definitive proof of whether an image is AI-generated or authentic.

Users should consider additional context when evaluating an image's authenticity.
